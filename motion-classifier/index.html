2. The weighted linear discriminant and its training

From measured features to one classification score. A linear classifier does not learn directly from the raw accelerometer waveform here. Each original trial becomes a two-feature vector, and the model takes a weighted sum:

z = w₁x₁ + w₂x₂ + b   →   p(Downstairs) = 1 / (1 + e−z)
x₁, x₂ — measured evidence
Acceleration STD and PSD band power, each standardized using training data (z-scores).
w₁, w₂ — learned weights
How each feature contributes to the decision score. Their signs and combined direction rotate the boundary.
b — learned bias
Shifts the decision boundary. The line z = 0 corresponds to probability p = 0.5.

This weighted-sum structure resembles the LDA projection from Page 02, but logistic regression learns its weights by minimizing cross-entropy, not by maximizing Fisher's criterion. These weights are in standardized-feature coordinates; their values are not direct physical sensor coefficients.

What does cross-entropy measure? Each real trial has a known label y: 0 = Upstairs, 1 = Downstairs. The model assigns probability p to Downstairs. A confident correct prediction has small loss; a confident wrong prediction has large loss.

ℓ(y,p) = −[y log(p) + (1−y) log(1−p)]

For an Upstairs trial (y = 0), loss = −log(1−p). For a Downstairs trial (y = 1), loss = −log(p). The training loss is the average of this quantity across the development trials.

Gradient descent adjusts the weights and bias to reduce that average loss. The held-out subjects are only evaluated—not used for gradient updates. At step 0, all three parameters start at zero, so p = 0.5 and each trial has loss ln(2) ≈ 0.693.

How to read the purple line

The purple line is not a trendline fitted through the dots. It contains all feature combinations for which the model is exactly undecided: p(Downstairs) = 0.5. The model predicts a class from which side a feature point lies on—even when that prediction disagrees with the dot's measured label.

Decision boundary will appear once training begins.

Pale blue: predict Upstairs (p < 0.5) Pale orange: predict Downstairs (p > 0.5) Green arrow: increasing Downstairs probability (+w direction)

The weights and prediction regions will update with each training step.

The learned weight vector w = (w₁,w₂) is normal (perpendicular) to the decision boundary in standardized feature coordinates, not tangent to the purple line. Visual angles may appear slightly distorted because the graph's horizontal and vertical scales differ.

What probability does cross-entropy penalize?

The highlighted point will show one real trial's current prediction and loss.

Why is the curve asymmetric for a given class? Confidently predicting the wrong class is penalized much more than giving the correct class a moderate probability.

Individual trial loss ≠ training loss. The selected point contributes one loss term. Training minimizes the average over all development trials. Changing this selection only changes the explanation shown—it does not retrain the classifier.

4. When is a well-trained model trustworthy?

Observe: Does training loss decrease? Does the decision boundary change? Does a lower training loss necessarily mean fewer mistakes on new participants? What if the loss curves behave differently?

Do not force an overfitting story. A simple 2D linear classifier may not exhibit classic increasing validation loss with more training. Differences between participants are another possible explanation. The four held-out participants have already been examined in this course; their results are diagnostic, not untouched final-test performance.
Show the mathematical model

Logistic regression: p = sigmoid(w1*x1 + w2*x2 + b). Cross-entropy: L = −mean[y log(p) + (1−y) log(1−p)]. Gradient descent: theta(k+1) = theta(k) − learningRate * gradient(L). The zero-score line is the current linear decision boundary.
