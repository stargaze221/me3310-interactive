2. One Gaussian Kernel, many training samples

In all three panels, x is a new 2D measurement and xᵢ is a training sample:

K(x, xᵢ) = exp(−‖x − xᵢ‖² / (2σ²))

For this classroom demonstration, each class contributes with equal magnitude per training sample within that class: aᵢ = +1 / N₊ for Class + and aᵢ = −1 / N₋ for Class −. The coefficients are fixed by this illustrative rule; they are not learned.

f(x) = Σᵢ₌₁ᴺ aᵢ K(x, xᵢ) + b    and    predicted class = sign(f(x))

3. Where is the infinite-dimensional feature space?

This is the key mathematical connection. A Gaussian Kernel is the inner product of two feature vectors in a countably infinite-dimensional space:

K(x, x′) = ⟨φ(x), φ(x′)⟩

Infinite-dimensional representation

φ(x) = (φ₀₀, φ₁₀, φ₀₁, φ₂₀, φ₁₁, φ₀₂, …)

Each 2D measurement is mapped to infinitely many coordinates. We do not construct this vector numerically.

⇔

Finite kernel evaluation

K(x, xᵢ) = exp(−‖x − xᵢ‖² / (2σ²))

One kernel evaluation computes the exact inner product of the two infinite-dimensional feature vectors.

Now choose a weight vector in feature space as a finite combination of mapped training samples:

w = Σᵢ₌₁ᴺ aᵢ φ(xᵢ)

Substitute into a linear classifier in feature space:

f(x) = ⟨w, φ(x)⟩ + b = Σᵢ₌₁ᴺ aᵢ ⟨φ(xᵢ), φ(x)⟩ + b = Σᵢ₌₁ᴺ aᵢ K(xᵢ, x) + b

Infinite features, but only N kernel evaluations. The classifier is linear in φ(x), even though its decision boundary f(x)=0 can be curved and disconnected in the original 2D space.

Optional mathematics: what are the infinite Gaussian features for a 2D input?

For x=(x₁,x₂), one valid Gaussian feature mapping has one coordinate for each pair of nonnegative integers (p,q):

φₚq(x) = exp(−‖x‖²/(2σ²)) · (x₁/σ)ᵖ (x₂/σ)ᑫ / √(p! q!)

The index pairs (p,q) are countably infinite. Multiplying and summing corresponding coordinates gives

Σₚ₌₀∞ Σᑫ₌₀∞ φₚq(x) φₚq(x′) = exp(−‖x−x′‖²/(2σ²))

The infinitely many coordinates are not drawn as a literal 3D surface here. The graphs show the original 2D measurements, one exact kernel evaluation, and their finite signed sum.

Important distinction: The finite list (K(x,x₁), …, K(x,xᴺ)) is a list of similarities to N training samples. It is not the full infinite-dimensional Gaussian feature vector φ(x). The equivalence above comes from the inner-product identity and the particular choice w = Σ aᵢ φ(xᵢ).

4. Experimental interpretation

We can build a flexible classifier using similarities to measured training examples. Increasing the number of samples changes how many terms contribute to the decision boundary; changing σ changes the region of influence of each sample.

Think about it: Does a smooth boundary prove that the measured classes are genuinely different? What new trials would we need to test whether this classifier generalizes?
