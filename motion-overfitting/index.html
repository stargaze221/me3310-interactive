More Features: Better Model, or Overfitting?

Train the same linear classifier on 4, 8, 12, or 16 measured IMU features. Does improvement in the training data carry over to an unfamiliar participant?

1. The experimental comparison

Loading actual USC-HAD measurements…

Controlled: same 140 original trials, fixed preprocessing, same linear logistic regression, same full-batch optimization method.
Varied: number of input features: 4 → 8 → 12 → 16. The feature order is fixed before looking at held-out performance.

Data: 14 subjects × 5 original Upstairs trials × 5 original Downstairs trials. Each trial has one 16-feature vector formed by averaging feature measurements over 3-second windows with 0.5-second hop. Overlapping windows are not independent experimental trials. Actual USC-HAD 100 Hz acceleration and gyro measurements only; no artificial points.

3. What information did we give the model?

The comparison uses nested, predeclared feature sets: columns 1–4, 1–8, 1–12, and 1–16 in our existing MATLAB extraction order. These are not Fisher-ranked or tuned using the evaluation subjects.

    Adding features increases the number of learned coefficients, but it does not automatically mean the model will overfit. Some new features may be redundant, some informative, and some sensitive to noise. This example is not a controlled feature-selection search.

    4. Interpreting evidence: overfitting versus generalization

    Training fit
    z = b + w₁x₁ + ··· + wpxp

    For each feature count p, optimize the same logistic cross-entropy objective on training participants. More features let a linear classifier use more directions, but optimization and finite data still matter.

    New-subject prediction
    p(Downstairs) = 1/(1 + e−z)

    Evaluate on participants excluded from that particular model fit. Accuracy tests the predicted class; cross-entropy additionally penalizes confident incorrect predictions.

    Evidence is not a predetermined story. If 16 features improve held-out performance, the measured evidence supports that improvement under these conditions. If training improves but held-out performance declines, investigate possible overfitting, noise, correlation, or subject differences. A single split is not enough to establish a universal model ranking.
