Monte Carlo Regression Explorer

Repeat the same calibration experiment computationally and watch finite-sample variation move the fitted regression line.

What experiment are we simulating?

Imagine a sensor with a fixed, underlying calibration relationship. We control a known input x, measure the sensor output y, and use a finite number of measurements to estimate the calibration line.

True model:  y = 2 + 3x + ε    with    ε ~ N(0, σ²)
What stays fixed?
  • True intercept: b₀ = 2
  • True slope: b₁ = 3
  • Known inputs x are evenly spaced from 0 to 5
  • The selected noise level σ
What changes randomly?
  • Each measurement receives a new random error εᵢ
  • The measured y-values therefore change
  • The fitted intercept b̂₀ and slope b̂₁ change

One finite-sample experiment

  1. Choose n known inputs. The simulator places n values evenly from x = 0 to x = 5.
  2. Measure the sensor output. For each xᵢ, generate yᵢ = 2 + 3xᵢ + εᵢ.
  3. Fit a regression line. Use least squares to estimate ŷ = b̂₀ + b̂₁x.
  4. Record the estimate. One experiment contributes one value of b̂₁ to the histogram.
Monte Carlo step: repeat the entire finite-sample experiment many times using the same true model, same x locations, same n, and same σ, but draw new independent measurement errors each time. The resulting histogram shows the distribution of slope estimates we could obtain from repeated experiments.

What should you notice?

  • The true calibration relationship is unchanged across repetitions.
  • Random measurement variation produces different finite datasets.
  • Different datasets produce different estimates of the slope and intercept.
  • Increasing n usually makes the distribution of estimated slopes narrower.
Optional Insight: Monte Carlo and the Curse of Dimensionality

Suppose you try to cover a parameter space with the same number of grid values in every dimension. The required number of combinations grows exponentially.

10,000 Monte Carlo samples in 2 dimensions correspond to about 100 samples per dimension.

Monte Carlo avoids exhaustive grid enumeration, but it does not make a high-dimensional space dense. High-dimensional spaces remain sparse.
