Monte Carlo Regression Explorer

Repeat one calibration experiment computationally, then connect the fitted line to residuals, confidence intervals, prediction intervals, and repeated-experiment coverage.

What experiment are we simulating?

Imagine a sensor with a fixed underlying calibration relationship. We control a known input x, measure the sensor output y, and use a finite number of measurements to estimate the calibration line.

True model:  y = 2 + 3x + ε    with    ε ~ N(0, σ²)
What stays fixed?
  • True intercept: b₀ = 2
  • True slope: b₁ = 3
  • Known inputs x are evenly spaced from 0 to 5
  • The selected noise level σ
What changes randomly?
  • Each measurement receives a new random error εᵢ
  • The measured y-values change
  • The fitted intercept b̂₀ and slope b̂₁ change
  • The residuals and confidence intervals change

One finite-sample experiment

  1. Choose n known inputs. The simulator places n values evenly from x = 0 to x = 5.
  2. Measure the sensor output. For each xᵢ, generate yᵢ = 2 + 3xᵢ + εᵢ.
  3. Fit a regression line. Use least squares to estimate ŷ = b̂₀ + b̂₁x.
  4. Inspect residual evidence. Compute eᵢ = yᵢ − ŷᵢ and estimate the residual standard deviation.
  5. Quantify uncertainty. Build a 95% confidence interval for b₁ and bands around the fitted response.
Monte Carlo step: repeat the entire finite-sample experiment using the same true model, same x locations, same n, and same σ, but draw new independent errors each time. Because the simulation knows the true slope b₁ = 3, it can also check how often the nominal 95% slope confidence interval actually contains the truth.

What should you notice?

  • The true calibration relationship stays fixed, but finite samples produce different fitted lines.
  • Residuals show the measurement-to-model discrepancies left after fitting.
  • Increasing n usually narrows the distribution of slope estimates and the confidence interval.
  • A prediction interval is wider than a confidence band because a future measurement at a specified x contains new measurement noise.
  • A 95% confidence procedure is a repeated-experiment statement: across many repetitions, about 95% of intervals should contain the true parameter under the stated model assumptions.
Optional Insight: Monte Carlo and the Curse of Dimensionality

Why can Monte Carlo remain useful in high dimensions? It does not try to cover the entire parameter space densely. Instead, it estimates quantities such as an expected value using a sample average.

Monte Carlo estimator:  ÎN = (1/N) Σ f(Xi)
Estimator variance:  Var(ÎN) = Var[f(X)] / N
Estimator SD:  SD(ÎN) = σf / √N

The characteristic Monte Carlo sampling rate is therefore 1/√N. Dimension d does not appear in the exponent of N. However, dimension can still make the problem harder through the problem-dependent variance term σf², rare events, poor sampling distributions, or more expensive model evaluations.

Useful way to think about it: for plain Monte Carlo integration, much of the dimensional difficulty is pushed into the variance/problem structure rather than into the N−1/2 convergence exponent.

Compare that statistical averaging idea with an exhaustive grid. If you use the same number of grid values along every dimension, the number of combinations grows exponentially.

Exhaustive grid combinations100,000
Grid-equivalent linear resolution, N^(1/d)6.31
Monte Carlo sampling factor, 1/√N0.0100
Estimator SD, σf/√N0.0200

With N = 10,000 and d = 5, a dense grid would be expensive while 10,000 Monte Carlo samples remain geometrically sparse. The sampling factor is 1/√N = 0.0100; with σf = 2.0, the estimator SD is about 0.0200.

Do not interpret N^(1/d) literally. It is only a geometric heuristic: if N total points were arranged like an equally spaced grid in d dimensions, each axis would have about N^(1/d) locations. It is not the Monte Carlo error rate. Dimension may still affect σf and other problem-specific difficulty.
