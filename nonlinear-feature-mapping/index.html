Nonlinear Mapping → Linear Separation

How can one flat separating plane become a curved boundary in the original measurement space? Start with the circles. Then try three separate islands and two moons.

The idea: Original measurements (x₁, x₂) can be difficult to separate with one straight line. Create an additional nonlinear feature z = g(x₁, x₂). In the new 3D space, a flat plane z = t can separate the classes. Looking back in the original 2D space, that same rule g(x₁, x₂) = t is a curved boundary.

Key idea for Experimental Methods I

Nonlinear in the original space does not mean nonlinear in every space. If the right nonlinear features are available, the separating rule can be linear in the mapped space. The complex-looking 2D boundary is simply the original-space view of that linear rule.

Next lesson — Gaussian Kernel SVM: Instead of manually choosing a few features, the Gaussian kernel provides inner products for a much richer, infinite-dimensional feature space. An SVM then learns a linear separator there; its boundary in the original measurement space can be nonlinear.

Interpretation notes: These are synthetic classroom data, and the mapped planes are specified for illustration—not learned by SVM optimization. The Gaussian examples use a finite number of explicit radial-basis features, not the full infinite-dimensional Gaussian feature map. The displayed percentages are on these example points, not independent-test accuracy. A classifier must still be validated on independent experimental trials.
