What should you notice?

  • Probability starts with a model and describes possible data. Here we do the opposite: the data are fixed and we compare parameter values.
  • The likelihood is largest when the candidate line makes the observed residuals collectively small.
  • For Gaussian measurement errors with fixed σ, the slope that maximizes likelihood is the same slope that minimizes SSE.
  • Changing σ changes how sharply likelihood penalizes residuals, but it does not change the SSE curve itself.
