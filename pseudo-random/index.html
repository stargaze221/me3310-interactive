Pseudo-Random Number Explorer

See how a deterministic seed can generate a repeatable sequence that still behaves statistically like random samples—and how those samples become measurement noise in Monte Carlo experiments.

How can a computer generate “random” numbers?

A pseudo-random number generator (PRNG) begins with a seed and repeatedly applies a deterministic rule. The resulting sequence is not fundamentally random, but it can be designed to have statistical properties that make it useful for simulation.

Illustrative rule:   xk+1 = (a xk + c) mod m,    uk = xk/m
Important: this explorer uses a simple linear congruential generator so the idea is transparent. MATLAB and other scientific tools may use more sophisticated PRNG algorithms, but the key concept remains: same algorithm + same seed → same sequence.

From PRNG to a Monte Carlo Calibration Experiment

Use seed A to generate normal samples zᵢ, convert them to measurement errors εᵢ = σzᵢ, and then create one noisy calibration dataset.

εi = σ zi,    zi ~ N(0,1),    yi = 2 + 3xi + εi

Keep the same seed and press Generate again: the same noise values and the same calibration dataset reappear. Change the seed: the physical model stays fixed, but a different finite dataset appears.

Connection to MATLAB

In MATLAB, the implementation details are handled for you. The seed is useful when you need a simulation to be reproducible.

rng(42) % Set a reproducible seed z = randn(n,1); % Standard normal pseudo-random samples epsilon = sigma*z; % Measurement noise y = 2 + 3*x + epsilon; % One simulated calibration experiment

Running the same code again after resetting rng(42) reproduces the same pseudo-random sequence. Changing the seed produces another sequence.

Try This

  1. Set Seed A = 42 and Seed B = 42. Generate the sequences. Do they match?
  2. Change only Seed B to 43. The sequences now differ, even though the generator itself has not changed.
  3. Compare 20 samples with 10,000 samples. Which histogram better represents the target distribution?
  4. Keep Seed A fixed and change σ. The underlying pseudo-random z-values are repeatable, but the physical measurement-noise magnitude changes.
  5. Return both seeds to 42. Ask yourself: if the numbers are deterministic, why can they still be useful for Monte Carlo analysis?
Takeaway: pseudo-random does not mean uselessly fake. A PRNG gives us statistically useful, controllable, and reproducible samples. Monte Carlo then uses those samples to represent repeated uncertain experiments computationally.
