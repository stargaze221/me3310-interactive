Pseudo-Random Number & Inverse CDF Explorer

Follow the computational chain from a deterministic seed to uniform pseudo-random numbers, then transform those numbers into a desired probability distribution and finally into simulated measurement noise.

1. The starting point: a reproducible uniform sequence

A pseudo-random number generator (PRNG) begins with a seed and repeatedly applies a deterministic rule. A convenient starting distribution is the uniform distribution on the interval from 0 to 1.

xk+1 = (a xk + c) mod m,    Uk = xk/m,    Uk ∈ (0,1)
Same algorithm + same seed → same uniform sequence. That reproducibility is useful when we need to debug, verify, or repeat a Monte Carlo study.

2. How do uniform numbers become a normal distribution?

A PRNG can give us values that behave like U ~ Uniform(0,1). To simulate another distribution with cumulative distribution function F, one general idea is inverse transform sampling:

U ~ Uniform(0,1)    →    X = F−1(U)

For a standard normal variable, the target CDF is Φ, so

U ~ Uniform(0,1)    →    Z = Φ−1(U)    →    Z ~ N(0,1)

Uniform input:

U = 0.800

Normal quantile:

Z = Φ−1(U) = 0.842

For example, U = 0.5 maps to Z = 0 because half of a standard normal distribution lies below zero.

Important implementation note: this explorer deliberately uses the inverse-CDF idea because it makes the probability transformation visible. MATLAB randn and other scientific libraries may use different, more efficient algorithms internally. The conceptual connection remains useful even when the implementation differs.

4. From probability distribution to simulated measurement noise

For the calibration model, transform uniform pseudo-random samples into standard normal values, then scale them by the assumed measurement-noise standard deviation.

Ui ~ U(0,1)   →   Zi = Φ−1(Ui)   →   εi = σ Zi   →   yi = 2 + 3xi + εi

Keep the same seed and press Generate again: the same uniform values, transformed normal values, and calibration dataset reappear. Change the seed: the physical model stays fixed, but a different finite dataset appears.

Connection to MATLAB

In MATLAB, the implementation details are handled for you. rand gives uniform pseudo-random values and randn directly gives standard-normal pseudo-random values.

rng(42) % Reproducible seed u = rand(n,1); % Uniform pseudo-random samples z = randn(n,1); % Standard-normal pseudo-random samples epsilon = sigma*z; % Measurement noise y = 2 + 3*x + epsilon; % One simulated calibration experiment

The inverse-CDF mapping shown above is a conceptual way to understand how uniform probability levels can be transformed into a target distribution; it is not a claim that MATLAB implements randn exactly this way.

Try This

  1. Move the CDF slider to U = 0.5. Why does it map to Z ≈ 0?
  2. Move U close to 0.99. Why does the corresponding Z move far into the positive tail?
  3. Set Seed A = 42 and Seed B = 42. Generate the sequences. Do they match?
  4. Change only Seed B to 43. What changes even though the target distribution stays the same?
  5. Compare 20 samples with 10,000 samples. Which histogram better represents the target distribution?
  6. Keep Seed A fixed and change σ. What stays reproducible, and what changes in the simulated measurement?
Takeaway: a useful Monte Carlo chain is seed → uniform pseudo-random numbers → probability transformation → simulated uncertainty → repeated experiment. The random-looking sequence is reproducible, while the chosen probability model determines what kind of uncertainty the simulation represents.
